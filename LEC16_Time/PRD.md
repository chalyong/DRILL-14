# 새 비행 기능 PRD

## 1. 개요

현재 월드에 `bird_animation.png`를 사용하는 새 비행 기능을 추가한다.
새 10마리가 화면 안에서 좌우로 반복 이동하며 날갯짓 애니메이션을 재생해야 한다.

## 2. 확정 사항

- 새의 비행 속도: **40km/h**
- 날갯짓 1회에 사용하는 스프라이트: **14프레임**
- 날갯짓 1회당 이동 거리: **2.6m**
- 새의 수: **10마리**
- 이동 방향: 좌우 왕복
- 애니메이션 이미지: `bird_animation.png`
- 기존 소년의 이동 및 입력 동작은 변경하지 않는다.

## 3. 속도 및 애니메이션 계산

### 3.1 실제 이동 속도

```text
40km/h = 11.111...m/s
```

현재 월드의 픽셀 환산 기준은 `10px = 0.3m`이므로:

```text
11.111...m/s × (10px / 0.3m) = 약 370.37px/s
```

### 3.2 날갯짓 애니메이션 속도

```text
날갯짓 횟수/초 = 11.111...m/s ÷ 2.6m = 약 4.273회/s
프레임/초 = 4.273회/s × 14프레임 = 약 59.83FPS
```

따라서 새의 애니메이션 프레임 속도는 다음 계산 결과를 사용한다.

```python
FLY_FRAME_PER_SECOND = 59.83
```

실제 프레임 갱신은 `game_framework.frame_time`을 사용하여 프레임 속도와
게임 실행 속도를 분리한다.

## 4. 기능 요구사항

### 4.1 새 객체

- 새의 이미지, 위치, 현재 프레임, 이동 방향을 관리한다.
- 새 객체의 `update()`에서 프레임과 위치를 갱신한다.
- 새 객체의 `draw()`에서 현재 애니메이션 프레임을 화면에 출력한다.

### 4.2 새 10마리 생성

- 게임 월드 초기화 시 새 객체를 10마리 생성한다.
- 각 새는 화면에 겹치지 않도록 서로 다른 시작 위치를 가진다.
- 새의 높이 또는 시작 위치에 변화를 주어 자연스럽게 보이도록 한다.

### 4.3 좌우 반복 이동

- 새는 지정된 비행 속도로 수평 이동한다.
- 화면의 좌우 경계에 도달하면 이동 방향을 반전한다.
- 새가 화면 밖으로 완전히 사라지지 않도록 경계 위치를 제한한다.

### 4.4 날갯짓 애니메이션

- `bird_animation.png`의 14개 스프라이트를 순서대로 반복 재생한다.
- 애니메이션 프레임은 매 업데이트마다 증가시키되, `frame_time`을 곱한다.
- 마지막 프레임 다음에는 첫 프레임으로 순환한다.

## 5. 비기능 요구사항

- 기존 게임 루프와 `game_world` 객체 관리 방식을 따른다.
- 기존 소년, 공, 잔디의 동작과 렌더링 순서에 영향을 주지 않는다.
- 새 기능은 새 모듈로 분리하여 유지보수 가능하게 한다.
- 입력 이벤트는 새 객체가 가로채지 않도록 한다.

## 6. 검증 기준

- 게임 시작 시 새가 정확히 10마리 생성된다.
- 모든 새가 `bird_animation.png`를 사용한다.
- 14프레임 날갯짓 애니메이션이 끊김 없이 반복된다.
- 새가 좌우 경계에서 방향을 바꾼다.
- 새의 이동 속도는 40km/h 기준인 약 370.37px/s이다.
- 날갯짓 애니메이션 속도는 약 59.83FPS이다.
- 기존 소년의 이동, 점프가 아닌 공 발사, 수면 및 입력 동작이 유지된다.
